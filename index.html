Chain Reaction Workbench

Add objects from the Toolkit, wire them together, then press Run.

Mouse

  • Drag a Toolkit item into the work area (or double-click it to drop it in the centre).
  • Click an object to select it and edit it in Properties. Drag to move; drag the round orange handle to rotate.
  • Blue handles: square ones change length (ramps, trampolines, curved-ramp ends); round ones set a curve's radius or a paddle's rest/flipped angle.
  • Paths (fuse, runner, dragon): drag the points; double-click the line to add a point; double-click a point to remove it. Set Wander randomly (along the ground, or anywhere) to let it roam instead, bouncing off what it bumps.
  • Shift/Ctrl-click to select several objects; Shift-drag empty space to box-select. Drag any selected object to move them all.
  • Drag empty space or middle-drag to pan. Wheel to zoom.

Touch (phone / tablet)

  • Tap a Toolkit item to add it to the middle of the view, then drag it into place.
  • Tap an object to select it; switch to Properties to edit it.
  • Double-tap a path to add a point, or a point to remove it.
  • One finger on empty space pans; two fingers pinch to zoom.
  • Turn on Multi (☰ menu) to tap several objects, or drag a box around them, then move, copy or delete them together.
  • Pull down on the top bar to refresh (handy when installed on the home screen).

Keyboard

  • Space run / pause
  • . step (Shift = 10 frames)
  • R restart
  • - / + speed
  • Del delete selection
  • Ctrl+D duplicate
  • Ctrl+C / V copy / paste (any layer)
  • Ctrl+A select all
  • Arrows nudge (Shift = 10px)
  • Ctrl+Z / Y undo / redo
  • Ctrl+S save · Ctrl+O open
  • F fit view · Esc deselect

Pinball

Give each paddle a Flip key in Properties (click the box, then press the key). While running, hold the key — or the matching on-screen button — to flip. Targets and bumpers can set off another object via When hit, trigger.

Buttons & countdowns

A Button gets an on-screen button in the command bar (plus an optional key). Pressing it while running, or bumping something into it, sets off up to three linked objects. A Countdown counts down on screen and sets off its linked objects at zero. Linked objects need their Trigger set to When touched.

Triggers

Every active object has a Trigger: At start, When touched (bumped by something moving, reached by a burning fuse, or hit by dragon fire), When touched by… one object you pick (only that object sets it off), or Never, plus an optional delay. Fuses and cannons are also lit by fire or by a fuse ending on them.

Challenges

🏆 Challenges (in the menu) has 130 built-in puzzles, from easy to very hard, with your progress. Load challenges… adds a challenge file someone has made (see CHALLENGE-PROMPT.md). Solve one by adding pieces until its 🏆 goal object goes off; stuck? Show solution loads it with the answer in place. In your own projects, tick 🏁 Completes the challenge on the object that marks success.

Challenge mode

Turn Challenge ON (next to Run) before saving to make a puzzle: everything already in the project is locked — players can look but not move, change or delete it — and they solve it by adding their own pieces. With the challenge OFF, use Challenge pieces at the top of the Toolkit to allow All pieces or Choose which ones (tick them on the tiles). The challenge setting is saved with the file; Challenge OFF unlocks everything again.

Layers

Each layer is its own scene, shown as a tab. Close a tab to put the layer away; reopen it from the Layers menu. All layers are saved together in one .json project file.

To move an object to another layer, select it, press Copy (Ctrl+C), switch tabs and press Paste (Ctrl+V). A Gateway links layers: when something arrives in it (whatever started inside doesn't count), it switches to its target layer after the set time and runs it.

Size & running

Most objects have a Size in Properties (objects with their own size settings, like ramps, stairways and text, don't) (1 = normal, 2 = twice as big). A run stops by itself once nothing has happened for 3 seconds; press Run to carry on. On a phone, the panels hide while a run is in progress.
