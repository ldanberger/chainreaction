Chain Reaction Workbench

Add objects from the Toolkit, wire them together, then press Run.

Mouse

  • Drag a Toolkit item into the work area (or double-click it to drop it in the centre).
  • Click an object to select it and edit it in Properties. Drag to move; drag the round orange handle to rotate.
  • Blue handles: square ones change length (ramps, trampolines, curved-ramp ends); round ones set a curve's radius or a paddle's rest/flipped angle.
  • Paths (fuse, runner, dragon): drag the points; double-click the line to add a point; double-click a point to remove it.
  • Drag empty space or middle-drag to pan. Wheel to zoom.

Touch (phone / tablet)

  • Tap a Toolkit item to add it to the middle of the view, then drag it into place.
  • Tap an object to select it; switch to Properties to edit it.
  • Double-tap a path to add a point, or a point to remove it.
  • One finger on empty space pans; two fingers pinch to zoom.
  • Pull down on the top bar to refresh (handy when installed on the home screen).

Keyboard

  • Space run / pause
  • . step (Shift = 10 frames)
  • R restart
  • - / + speed
  • Del delete selection
  • Ctrl+D duplicate
  • Arrows nudge (Shift = 10px)
  • Ctrl+Z / Y undo / redo
  • Ctrl+S save · Ctrl+O open
  • F fit view · Esc deselect

Pinball

Give each paddle a Flip key in Properties (click the box, then press the key). While running, hold the key — or the matching on-screen button — to flip. Targets and bumpers can set off another object via When hit, trigger.

Triggers

Every active object has a Trigger: At start, When touched (bumped by something moving, reached by a burning fuse, or hit by dragon fire) or Never, plus an optional delay. Fuses and cannons are also lit by fire or by a fuse ending on them.

Layers

Each layer is its own scene, shown as a tab. Close a tab to put the layer away; reopen it from the Layers menu. All layers are saved together in one .json project file.
